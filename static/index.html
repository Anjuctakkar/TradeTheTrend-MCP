Funding rules (MTF, interest, charges)

Used by Portfolio analysis when you choose "Own capital + MTF", and for charges and net P/L. Saved to your account, so they follow you to any device. Brokerage, DP and pledge values start as placeholders: enter your broker's.
One stock per line: SYMBOL 3x (leverage), SYMBOL 25% (own margin) or SYMBOL none (not on MTF). Stocks not listed use the default leverage. Leverage is limited to 1x to 4x (minimum own margin 25%). Lines starting with # are notes.
Charges
GST applies to brokerage, exchange, SEBI, DP and pledge fees, not to STT or stamp duty. Statutory rates are pre-filled from current NSE delivery rates and can change.

NSE connection

Checks that both NSE MCP servers answer and how fast. If a server is slow or down, analysis, backtests and the assistant's lookups will time out, whatever is set up on this side.
The app waits up to 60 seconds per request and tries twice. Change this with NSE_READ_TIMEOUT, NSE_RETRIES and NSE_MAX_INFLIGHT in your .env file, then restart.

Getting a key

  • Create a key in the Anthropic Console, API keys, and copy it when it is shown. It isn't shown again.
  • The key needs credit to work. Add some under Plans & Billing. "Credit balance is too low" means there is none left.
  • If a link has moved, look for API keys or Plans & Billing in the Console's Settings menu.
  • This page only works from the computer running the dashboard. Don't share the key or put it in website code.
